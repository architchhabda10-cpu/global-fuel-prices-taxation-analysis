# Deployment checklist

Use this after copying the bundle into the existing repository.

- [ ] Confirm the public dataset can legally be shared.
- [ ] Copy/merge `README.md`, `index.html`, `DASHBOARDPREVIEW.png`, `PROJECT_REPORT.pdf`, `PERFORMANCE_TESTING.md`, `performance-test-results.json`, `requirements-test.txt`, `assets/`, `sql/`, and `tests/` into the repository root.
- [ ] Keep `global_fuel_prices_Dataset.csv` and `Global_Fuel_Prices_Taxation_Dashboard.twbx` in the root.
- [ ] Preview changes in GitHub Desktop.
- [ ] Commit with summary `Add interactive web dashboard and project documentation`.
- [ ] Push to GitHub.
- [ ] Open Settings -> Pages; deploy from `main` and `/(root)`.
- [ ] Open the published URL and verify KPI values, filters, charts, CSV download and resource links.
- [ ] Run a hosted Lighthouse/DevTools performance audit and save the real results.
- [ ] Add the demo video link after uploading the recording to an accessible share location.
